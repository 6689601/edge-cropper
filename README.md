# 픽셀 경계 크롭

이미지의 뚜렷한 직선 색 경계를 감지해 크롭 프레임을 가까운 경계에 맞춰주는 브라우저 도구입니다.

[앱 열기](https://6689601.github.io/edge-cropper/)

## 사용 방법

1. **이미지 선택**을 누르거나 이미지를 작업 영역에 끌어다 놓습니다. PNG, JPG, WEBP 이미지를 사용할 수 있습니다.
2. 크롭 프레임의 **모서리나 변을 안쪽으로 끌어** 자를 영역을 조절합니다. 프레임 안을 끌면 프레임을 이동할 수 있고, 프레임 바깥에서 끌면 새 영역을 선택할 수 있습니다.
3. **경계 스냅**을 켜면 프레임이 가까운 색 경계에 맞춰집니다. **스냅 거리**와 **경계 최소 길이**를 조절해 감도와 감지할 경계의 길이를 바꿀 수 있습니다.
4. **다시 설정**으로 전체 이미지 크기로 돌아가고, **PNG 저장**으로 크롭 결과를 다운로드합니다.

## 이미지와 개인정보

이미지와 크롭 작업은 브라우저 안에서 처리됩니다. 선택한 이미지가 별도 서버로 업로드되지 않습니다.

## 배포

이 앱은 빌드 과정이나 별도 서버가 필요 없는 단일 정적 HTML 앱입니다. GitHub Pages를 사용하려면 저장소의 **Settings → Pages**에서 **Deploy from a branch**를 선택하고 `main` 브랜치의 `/(root)` 폴더를 지정하세요.
